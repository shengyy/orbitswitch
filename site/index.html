Three tabs · Three coding environments

One surface across your AI coding tools.

Each primary tab manages a distinct local coding environment and its CLI. OrbitSwitch reads and displays the coding quota windows reported by each tool — never conflating them with consumer web chat limits.

TAB 01 macOS verified · Windows in CI

Gemini → Antigravity

Google Antigravity IDE & agy CLI

Antigravity.app agy PRO · ULTRA · FREE
  • Adopts your active Antigravity sign-in automatically and adds further Google accounts in the browser.
  • Shows 5-hour and weekly remaining share for Gemini and Claude/GPT model groups with reset times.
  • Confirms first, closes Antigravity & agy CLI, verifies the new sign-in, and rolls back on failure.

  • Displays the windows and reset times actually reported. Weekly-only accounts have no 5-hour bar.
  • Switches local Codex desktop and codex CLI credentials only after explicit user confirmation.
TAB 03 Desktop binding verified · switching beta

Claude → Claude Code

Anthropic Claude Code & claude CLI

Claude Code claude PRO · MAX

  • Shows 5-hour and weekly model windows (Sonnet & Opus) alongside exact reset countdowns.
  • Confirms before updating local Claude Code and desktop credentials, preserving prior state on error.
!
Coding tool quota ≠ consumer web chat quota

OrbitSwitch displays the rate-limit windows reported by Antigravity, Codex, and Claude Code. Usage on consumer web interfaces (such as gemini.google.com or chatgpt.com) follows separate product rules and is not equivalent to coding client quota.

Deliberate switching sequence

Confirmed by you. Protected by rollback.

You may have agent tasks running. OrbitSwitch never rotates accounts silently in the background and never touches local credentials before verifying the target account.

  1. 01

    Spot headroom at a glance

    Quotas refresh every 5 minutes and on open. Windows below 35% turn amber, below 10% turn red, and the account with the most headroom is tagged Most left.

  2. 02

    Confirm inside the panel

    Clicking an account slides up an in-surface sheet (Enter confirms, Esc cancels) that explicitly names the desktop app, language server, helpers, and CLI to be closed or updated.

  3. 03

    Verify auth, roll back on failure

    Target authorization is checked before any local state changes. If writing or verifying the new sign-in fails, the previous account is restored automatically.

  4. 04

    Keep desktop & CLI aligned

    Once verified, the target client reopens or syncs on the selected account so you can continue working without manual sign-out loops.

Local by design

Your accounts stay with you.

A small local utility. Sign in with the official clients, keep control of every switch, and see where your quota stands.

System credential storage

Saved credentials and paired desktop sign-ins stay in macOS Keychain or Windows Credential Manager. Tokens and cookies never reach the interface.

No cloud, no proxy, no telemetry

There is no self-hosted backend, no analytics script, and no model traffic relay. Network calls go only to official provider endpoints and GitHub Releases.

No auto-rotation or account sharing

Designed strictly for one person managing their own accounts on their own machine. OrbitSwitch never switches accounts automatically when quota runs out.

Transparent verification status

Identity and quota reads are checked against real installations. End-to-end switch verification is recorded separately in the project status.

Get started

Install in three steps

  1. Download the installer

    Grab the universal .dmg for macOS 26+ (Apple silicon & Intel) or the -setup.exe installer for Windows 10/11 x64 from GitHub Releases. Install the corresponding coding client first.

    macOS .dmg · Windows -setup.exe · GitHub Releases

  2. First launch (unsigned builds)

    Builds do not use an Apple Developer ID or Windows commercial certificate yet. On macOS, right-click the app and choose Open, or clear quarantine: 

    xattr -dr com.apple.quarantine /Applications/OrbitSwitch.app

    On Windows, choose More info → Run anyway in SmartScreen.

  3. Open from menu bar or tray

    Open the icon in your menu bar or tray. Choose a platform, then add or import an account. Claude Desktop needs a one-time link to the same Claude Code account and workspace.

Details

Frequently asked questions

Which clients can I manage?

Gemini manages Antigravity, ChatGPT manages Codex, and Claude manages Claude Desktop with Claude Code. Each tab keeps its own accounts, current sign-in and quota.

How do I add an account?

Add opens the official browser sign-in without changing your current CLI account. To include Claude Desktop, sign into the same account and workspace in Desktop and Claude Code, then import the pair.

Is coding quota the same as Gemini web or ChatGPT web chat quota?

No. OrbitSwitch reads the rate-limit windows (5-hour and weekly remaining share) reported for the coding environments — Antigravity, Codex, and Claude Code. Those windows are separate from consumer web chat allowances.

Why does switching ask for confirmation instead of hot-swapping?

A confirmed switch closes the affected desktop app and CLI processes, applies the verified account, and reopens the desktop app. Reopen CLI sessions yourself. Credential failures trigger restoration of the previous sign-in.

What is verified across platforms right now?

Antigravity switching has been tested on macOS. Codex and Claude identity/quota reads, plus Claude Desktop binding, are verified read-only. Real Codex/Claude switching and native Windows behavior remain unverified; see docs/status.md for scope.
